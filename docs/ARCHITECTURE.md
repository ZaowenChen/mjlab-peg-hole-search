# 架构与兼容边界

本仓库是当前开发主线，包名继续使用 `mjlab_contact_prep`。本次文件整理归档旧入口，保持控制阈值、PPO 奖励和既有实验统计。

| 目录 | 职责 |
|---|---|
| `simulation/` | 模型、资产、碰撞、后端、复位与随机采样 |
| `control/` | 控制与动作执行公共 API |
| `envs/` | PPO 观测、动作、奖励与终止公共 API |
| `data/` | 完整状态库及格式兼容 |
| `training/`、`evaluation/` | 训练与评估公共 API |
| 顶层模块、`night_run/` | 当前行为实现；旧导入继续兼容 |
| `frozen_source.py` | 原哈希对应的源码解析与独立重放树构建 |

职责子包当前仍转发到顶层实现。停车、XY 跟踪和 SPIKE-013 协议已扩展这些实现，不能继续声称它们与 2026-09-23 正式源码逐字节一致。旧实验从对应快照恢复源码，原冻结清单不重写。

## 关键合同

- 控制器不读取未知孔位真值。真值仅用于复位、训练奖励和离线评估。
- 状态库保存物理、控制、动作、探测、停车和环境历史状态；不能只保存关节位置。
- 在线 `ready` 表示动作许可，严格 20 N 力稳定性由离线统计单独评估。
- 旧 `SearchEnv` 使用 40 ms 判定；正式 `BankEnv` 使用 101 个连续 2 ms 采样点；SPIKE-013 使用 351 个连续 2 ms 采样点。各自结果按协议解释。
- SPIKE-013 的终止在完整决策边界结算；故障和非有限数优先于成功。
- 策略请求、控制合成请求与实测速度是不同量；历史 `combined_vx/vy` 无效。
- 停车与 XY 跟踪候选默认关闭，保持其独立物理准入边界。
- 根目录 `evaluation/` 保存运行产物，源码中的 `evaluation/` 提供程序接口。
